# Учёт внеклассных мероприятий

**Программный модуль для автоматизации учёта воспитательной работы в школе.**

---

## Описание

«Учёт внеклассных мероприятий» — это консольное приложение, разработанное для автоматизации рабочих процессов заместителя директора по воспитательной работе МБОУ Стеклянская СОШ Купинского района. Модуль позволяет оперативно вести учёт классных часов, экскурсий, спортивных соревнований и других мероприятий, контролировать их проведение и формировать сводную информацию.

### Основные возможности
- Добавление нового мероприятия с указанием названия, даты, ответственного учителя, класса-участника и статуса.
- Просмотр полного списка внеклассных мероприятий.
- Поиск мероприятий по названию, ответственному, классу или дате.
- Изменение статуса мероприятия («Запланировано», «Проводится», «Завершено», «Отменено»).
- Удаление мероприятия из списка.
- Автоматическое сохранение данных в файл JSON.

---

## Архитектура

Модуль реализован по принципу многоуровневой архитектуры с разделением ответственности:

- `Event.cs` — модель данных (класс мероприятия).
- `DataManager.cs` — компонент управления данными (чтение/запись JSON через System.Text.Json).
- `EventsLogic.cs` — компонент бизнес-логики (обработка мероприятий).
- `UIModule.cs` — компонент пользовательского интерфейса (консольное меню).
- `Program.cs` — главный файл запуска.

## Требования

- .NET 6.0 SDK или выше.
- Операционная система: Windows 10/11, Linux, macOS.
- Внешние зависимости: отсутствуют (используется только стандартная библиотека .NET).

---

## Установка и запуск

1. Скачайте или клонируйте репозиторий:
   git clone https://github.com/bomjelita/events-manager.git
2. Перейдите в папку проекта:
   cd events-manager
3. Соберите проект:
   dotnet build
4. Запустите программу:
   dotnet run
